# Collaboration
Date: 10/05/26

## Code Reviews
- Start with AI review
- Request changes if you want to re-review
- Accept with comment if you *want* something changed
- Accept with task if you *need* something changed
- Ask questions until you understand
- PR descriptions should detail:
    - What changed
    - Why changed
    - Attach issues
    - How to test (AC)

## PRs
- Rebase on `main` before submitting
- One PR for each atomic change
- Stack smaller PRs for larger issues
- Draft PRs until ready

## Issues
- Create issues while you're working on something
- Track progress on Kanban board

## Daily Slack Up
- What you completed/merged
- What you are working on
- What you need from me

## Sprint Planning
- Monday
- What I *will* get done
- What I *want* to get done
- What I *didn't* get done

## CI/CD
- Check linting/formatting
- Check tests
